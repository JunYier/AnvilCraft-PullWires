# 结算与优先级

## 单向输送

每条连接都是一条**有向边**：只有**主端**能送电给**从端**，从端的富余不会回流。
所以「谁给谁电」在你右键绑定那一刻就定下了。

结算每 `powerGridTick` 拍跑一次：主端有富余、从端有缺口，才成交；两者缺一不可。

::: info
一主多从时，主端的富余按**优先级降序 → 建立时间升序**依次分配，先满足优先级高的。
:::

## 优先级（0–15）

| 项 | 说明 |
| --- | --- |
| 默认值 | 7 |
| 修改 | 手持**铁砧锤**，按住热键（默认左 Ctrl）**右键**要改的那根杆，在配置页中央的轮盘上选值：指向扇区或滚动滚轮移动选择，**左键点击盘面确认** |
| 含义 | 数值越大**越优先**拿到电 |

配置页里除了优先级，还有这根杆的**重连排序**（见下）。修改后不会有动作栏刷屏——目标杆的实时数值直接显示在铁砧锤的物品提示里。

## 重连排序

链路被亏电断路挂起后，从端会按周期来申请重连；一根主端同时收到多个申请时按排序逐个裁决。
排序是**每根杆一份**的，在配置页上调整：

| 按钮 | 含义 |
| --- | --- |
| 首要因素 | 「优先级优先」还是「需求优先」（需求 = 从端的平均缺口） |
| 主因素方向 | 升序 / 降序 |
| 副因素方向 | 副因素恒为「主因素之外的那一个」，这里只管它的方向 |

**时间因素固定升序、没有开关**：两个因素都相同时，先建立的链路先被考虑。
排序在**这根杆作为主端**裁决自己的申请时生效。

页面上**没有「排序来源」开关**：按下的任何一下都直接写进这根杆自己的排序设定。
服务端配置 `Settlement` 分组里的「重连排序」是**存档级默认**，
它只在**进世界后的头一次结算**时被复制一份给**还没有排序设定的杆**；**已经有设定的杆会被跳过**，
玩家调过的顺序不会被默认值盖掉，重复执行也不会产生第二次改动（幂等）。

## 锁定

手持铁砧锤 **右键**一根杆切换锁定。

**锁定的语义是「忽略红石造成的开关切换」**：锁定后给它红石，它的开关不会动，
既不会被断电，也不会因为断电再上电而触发「开关重启」式的重连。

锁定**不影响优先级**，两者互不干扰。

## 亏电断路

主端所在电网**连续亏电**超过 `manualLinkDeficitTicks`（默认 300 刻）时，
主端会按**平均净流出从大到小**依次挂起自己的连接，每挂一条重新评估是否仍然亏电。

被挂起的连接进入「已挂起」状态：**定义不删除**，只是停送电。
然后它会等待重连：从端所在电网稳定一段时间后按周期申请，主端不亏电就同意。
`manualLinkDeficitTicks = 0` 表示永不自动断开。

## 开关重启

把杆的开关**关掉再打开**（OFF → ON）时：

- 该杆的运行时值**全部重置**（亏电计时、净流出窗口、重连冷却）
- **链路定义保留**，被挂起的连接直接恢复

这是「手动拉好的线不该因为重启就没了」的实现方式。

## 怎么看懂提示

对着杆看，物品提示里会出现：

```text
电网统计：
  总耗电量：80 kW
  总发电量：160 kW
  总交换电量：40 kW     ← 本附属插入，与「总发电量」同级
拉电线（主端）：
  外送电量：16 kW       ← 本拍功率，为 0 时隐藏
  内收电量：8 kW
  优先级：7
锁定                    ← 仅锁定时出现
```

标题里的「主端 / 从端 / 主端 / 从端」表示这根杆在这张网络里的角色。
