# 绑定连接

绑定连接是「玩家显式指定哪两根杆相连」的方式，与自动组网互不干扰：
自动组网是**同网**（两杆并入同一张电网），绑定连接是**两网之间的单向电力通道**。

## 绑定与解绑

| 动作 | 结果 |
| --- | --- |
| **右键**一根已放好的杆 | 它成为**主端**，绑定写进你手里那件东西 |
| **shift + 右键**（对着空气也行） | 解除绑定 |

绑定**不消耗**：放下一根杆建立一条连接后，绑定仍在，可以继续放第二根、第三根。

## 四种建链方式

### 1. 放杆（手持杆物品）

手持一根杆右键主端 → 走到目标位置放下 → 建立连接。

### 2. 粘贴（手持已绑定的磁盘）

磁盘已经记着主端时，**右键另一根已经放好的杆** → 当场建链，被点的那根成为**从端**。
这一下不会覆盖磁盘里记的主端，所以可以连着粘到很多根杆上。

::: tip
空磁盘右键杆 = 把主端记进磁盘（相当于本体的「复制」）。
让它回到普通磁盘：shift 右键解除绑定。
:::

### 3. 副手磁盘 + 主手放杆

把已绑定的磁盘放在**副手**，主手拿杆放下 → 同样建立连接。
引导带与距离条照常显示。由配置项 `allowDiskBinding` 控制。

### 4. 调试命令

`/wires link <坐标A> <坐标B>` 直接建立 A → B。仅 OP，且只用于排查问题。

## 界面反馈

- **粒子引导带**：从主端顶端连到「方块放置预览轮廓的头部」，超出范围时暂停生成。
- **距离 Boss 条**：前 3/4 是绿色（在范围内），后 1/4 是红色（已超出）。
  主端是跨维度杆时改为满格绿色，显示「无距离限制」。
- **物品提示**：手持的杆/磁盘会显示三档范围与绑定状态（含主端坐标、优先级、锁定）。

## 失败提示

| 情况 | 提示 | 绑定 |
| --- | --- | --- |
| 超过主端的手动连接范围 | 超出手动连接范围（当前距离 / 上限） | **保留**，换个位置继续 |
| 两端跨维度但不是两根跨维度杆 | 跨维度连接只能在两根跨维度输电杆之间建立 | **保留** |
| 这两根杆之间已经有同向连接 | 这两根杆之间已经存在同向连接 | **保留** |
| 粘贴到主端自己 | 这根杆就是当前记下的主端 | **保留** |

失败音效与「超距断开」共用同一个音符盒音效。

::: info
`A → B` 与 `B → A` 是两条**独立**的连接，可以同时存在（互为主从）。
:::
