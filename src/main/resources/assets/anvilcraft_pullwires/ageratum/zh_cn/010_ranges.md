# 三档范围

每根输电杆都有三个距离，它们的用途完全不同，混起来看很容易出错。

| 档位 | 决定什么 |
| --- | --- |
| **供电范围** | 发电机、用电器、储电元件能不能并入这根杆所在的电网 |
| **自动组网范围** | 两根杆能不能**自动**连成同一张电网 |
| **手动连接范围** | 绑定连接最远能拉多远 |

三者必须满足 `供电 ≤ 自动组网 ≤ 手动连接`，否则会出现「连得上却供不上电」这种怪事。

## 距离怎么量

三档范围里的「距离」一律取**长边长度**：`max(|dx|, |dy|, |dz|)`。

也就是说，两根杆分别放在 `(0, 0, 0)` 与 `(6, 8, 0)` 时，距离算 **8**，而不是直线距离 10。

<info>
这样做的好处是斜角不会比直线更「亏」。本体的自动组网用的是包围盒相交，斜着摆时判定会变严格；本附属统一按长边长度算，规则更好记。
</info>

## 各杆取值
对于本模组的默认配置，有：

| 杆 | 供电范围 | 自动组网 | 手动连接 |
| --- | --- | --- | --- |
| 输电杆 | 8（本体的 R） | 24（3 倍） | 32（4 倍） |
| 远程输电桩 | 16（本体的 R） | 48（3 倍） | 64（4 倍） |
| 超远程输电杆 | 2 | 128（本体输电杆 R 的 16 倍） | 256（本体输电杆 R 的 32 倍） |
| 跨维度输电杆 | 0（不供电） | 0（不自动组网） | 不限距离 |

表中本体杆的格数是按**本体默认 R**（8 与 16）算出来的；改本体 R 会同时改变自动组网与手动连接范围。

## 为什么写成倍数

本体的 R 是**玩家可配置的**。如果本附属把连接范围写成方块数，玩家把 R 调大之后，就会出现「供电范围比自动组网范围还大」的越界，旧存档里的杆甚至会直接报错。

写成倍数之后，本体 R 怎么改都不会越界，减少可能的报错。

超远程杆的自动组网与手动连接也是倍数（16 倍 / 32 倍），但它的**供电范围固定为 2 格**——它几乎只用来当长距离中继，不负责就近供电。

## 放置提示

安装有本附属并手持任意杆时，如果当前瞄准的落点会落入某根已放置杆的**自动组网范围**内，屏幕下方会出现绿色的 `<>` 提示，表示「放下去就会并进那张电网」。

## 配置在哪

`config/anvilcraft_pullwires-common.toml` 的 `Transmission` 分组，每种杆一个折叠块。

<warning>
代码里的默认值只在**新建配置文件**时写入。如果你之前已经生成过配置文件，改动版本后需要手动修改或删掉该文件让它重新生成，否则读到的仍是旧值。
</warning>
