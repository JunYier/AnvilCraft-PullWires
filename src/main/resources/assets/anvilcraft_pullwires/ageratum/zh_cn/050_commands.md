# 命令与界面

## `/wires`

| 子命令 | 权限 | 作用 |
| --- | --- | --- |
| `guide` | 玩家 | 打开这份手册 |
| `list` | 玩家 | 列出当前所有连接及其状态 |
| `link 坐标A 坐标B` | OP | 直接建立 A → B |
| `unlink 坐标A 坐标B` | OP | 断开这两根杆之间的所有连接 |
| `clear` | OP | 这是破坏性操作！会删掉所有的连接！ |

坐标可以指向杆的**任意一段**，命令会自己找到顶段。

`link` / `unlink` 只用于排查问题——正常玩法请用绑定连接。

## `/wires display`

客户端命令，开关屏幕上的常驻连接列表：

| 用法 | 作用 |
| --- | --- |
| `/wires display` | 切换开关 |
| `/wires display true` | 常驻显示 |
| `/wires display false` | 关闭 |

列表每行显示一条连接：状态标记、主端的维度与坐标、从端的维度与坐标，以及这一拍的转移量。跨维度连接会显示「送出量 → 送达量（含损耗）」。

列表的位置、最大行数与缩放都在客户端配置里调整。

## 状态

| 状态 | 含义 |
| --- | --- |
| **活跃** | 两端都在线，正常输送 |
| **未接入** | 有一端离线或不在电网内，恢复后自动接通 |
| **已挂起** | 被亏电断路挂起，等待重连申请 |
| **待批准** | 从端已申请重连，等待主端裁决 |

四种状态的颜色可以在客户端配置的 `Graphics & Rendering` 分组里改。

## 配置文件

| 文件 | 内容 |
| --- | --- |
| `anvilcraft_pullwires-common.toml` | 三档范围、跨维度、结算与重连、连接开关 |
| `anvilcraft_pullwires-client.toml` | 线色、放置提示、连接列表、粒子与界面 |

配置界面里每一项都有说明文字，鼠标悬停即可看到。

## 与其它模组的集成

- **Jade**：注视输电杆时显示本附属的连接信息
- **JEI**：两种杆都有信息页，说明从合成表看不出的规则
- **藿香**：就是你现在读的这份手册，可用 `/wires guide` 随时重开
