# 跨维度输送

跨维度输电杆是本附属的第二种杆。它本身**不供电、不自动组网**，只作为连接的端点，并且**不受距离与维度限制**。

它的外形沿用本体远程输电桩的四段结构，所以放置方式与普通杆完全一样。

## 它是什么

| 项 | 行为 |
| --- | --- |
| 供电范围 | 0：类似普通的耗电元件，需要“被”入网 |
| 自动组网 | 0：任何距离都不会和别的杆自动连成电网 |
| 手动连接范围 | 不限距离 |
| 跨维度 | 允许 |


## 怎样跨维度

<warning>
只有**两端都是跨维度输电杆**时，才允许建立跨维度的连接。只要有一端是普通杆，跨维度就会被拒绝——否则随便配一根跨维度杆就等于白送跨维度输送。
</warning>

步骤：

1. 在任意维度右键一根跨维度杆，记下主端（建议用磁盘）
2. 穿过传送门，在目标维度右键另一根跨维度杆，或直接放下新的一根
3. 连接建立，两端杆顶开始出现传送门粒子

同维度的两根跨维度杆当然也能连，同样不受距离限制。

## 电力线

与其他杆一样，**同维度**的连接会正常绘制电力线；只有**真正跨越维度**的那条连接不画线，改用杆顶的传送门粒子表示连接状态。

## 单区块强加载

放下的跨维度杆会把**自己所在的那一个区块**设为强加载。

- 每根跨维度杆常驻 1 个区块，拆掉后解除
- 可以在配置里的 `crossDimensionalPoleForceload` 关闭


## 传输损耗

`crossDimensionalPoleLoss`（0.0 – 1.0，默认 0.0）只作用于**跨越维度**的连接。

损耗计在**主端**头上，而不是从送达量里扣：

```text
要送达 N，主端需要付出 N / (1 − 损耗)
```

例如损耗 0.2、从端需要 256，主端会付出 320、从端恰好收到 256。

如果主端可支配的电力不够这笔支出，就按它的实际额度送出，从端相应少收——表现为「从端欠压」，而不是把主端账面抽成负数。

<info>
损耗为 0 时，主端付出多少从端就收到多少。同维度的跨维度杆之间不存在损耗。
</info>

## 传送门粒子

连接处于**活跃**状态时，两端杆顶会持续散发传送门粒子。目前无法关掉。



## 其它

- 优先级、锁定、亏电断路、挂起重连、开关重启，与普通杆完全一致
