# 跨维度输送

跨维度输电杆是本附属唯一具备**真正新行为**的杆：它不供电、不自动组网，
只作为连接的端点，并且**不受维度与距离限制**。

它继承本体远程输电桩的四段结构，所以外观与放置方式完全一样。

## 三个「不」

| 项 | 行为 |
| --- | --- |
| 供电范围 | 0 —— 它只做链路端点 |
| 自动组网 | 不参与，任何距离都不会和别的杆自动连成电网 |
| 电力线渲染 | **任何情况下都不绘制线条**，用顶端的传送门粒子表示连接态 |

## 怎样才能跨维度

::: warning
只有**两端都是跨维度输电杆**时才允许跨维度连接。
只要有一端是普通杆，跨维度就会被拒绝——否则随便配一根跨维度杆就能白嫖跨维度输送。
:::

连接方式仍是绑定连接：

1. 在主世界右键一根跨维度杆 → 绑定主端
2. 走进传送门，在下界右键另一根跨维度杆（或直接放下新的一根）
3. 建立连接，两端顶端开始出现传送门粒子

同维度的两根跨维度杆当然也能连，同样**不受距离限制**（AC3.2.3）。

## 单区块强加载

跨维度链路的对端在别的维度，没人过去时那一侧会卸载，连接就只能停在「未接入」。
因此放下的跨维度杆会把**自己所在的那一个区块**设为强加载
（沿用本体「监督者」的加载机制，等级 0 = 恰好一个区块，不申请随机刻）。

- 每根跨维度杆常驻 **1 个**区块，拆掉后解除
- 可在配置里用 `crossDimensionalPoleForceload` 关闭
- 区块卸载或服务器停止时**不会**解除，否则重启后它再也不会自己加载

## 传输损耗

`crossDimensionalPoleLoss`（0.0–1.0，默认 0.0）：从端收到的是 `送出量 × (1 − 损耗)`，
差额直接消失，不退还给主端。**只有两端处于不同维度时才生效**——
同维度的两根跨维度杆之间没有「跨界传送」这回事。

## 传送门粒子

连接处于**活跃**状态时，两端杆顶持续散发传送门粒子：
在杆头周围随机位置出现，然后沿直线飞向杆头（用的就是原版下界传送门那套粒子运动）。
一旦挂起或断开，粒子立即停止。

## 其它

- 优先级、锁定、亏电断路、重连、开关重启——与普通杆完全一致
- `A → B` 与 `B → A` 并存不会造成功率翻倍：结算单向且局部守恒，
  同一拍内被补平的从端余量恰好为 0，不可能反过来再送出
