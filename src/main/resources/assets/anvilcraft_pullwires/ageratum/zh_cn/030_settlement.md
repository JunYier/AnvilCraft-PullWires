# 结算与优先级

## 单向输送

每条连接都是一条**有向边**：只有**主端**能送电给**从端**，从端的富余不会回流。

结算每 `powerGridTick` 拍跑一次，判据很简单：**主端有富余、从端有缺口**，两者缺一不可。

一主多从时，主端的富余按**优先级降序 → 建立时间升序**依次分配，先满足优先级高的。

<info>
多跳链路是支持的：从端拿到电以后，如果它自己也是别的连接的主端，它会用这些电去补下游的缺口。所以 `A → B → C` 能把电送到 C。
</info>

## 优先级

| 项 | 说明 |
| --- | --- |
| 范围 | 0 – 15 |
| 默认 | 7 |
| 含义 | 数值越大**越优先**拿到电 |
| 修改 | 手持**铁砧锤**，按住热键（默认左 Ctrl）**右键**要改的那根杆，在配置页里拖动滑条 |

滑条**松手时才提交一次**，拖动过程中不会连续发包；松手后等下一次服务端同步，数值就会对上。

## 每杆配置页

手持铁砧锤、按住热键右键杆，会打开这根杆自己的配置页。里面有三样东西：

| 控件 | 作用 |
| --- | --- |
| 优先级滑条 | 0 – 15，松手提交 |
| 首要因素 | 在「优先级」与「需求」之间切换 |
| 主因素方向 / 副因素方向 | 各自升序 / 降序 |

热键在「按键设置」里可以改（默认左 Ctrl）。

<warning>
配置页一次只开一页，且必须是**主手**拿着铁砧锤、当前没有别的界面。如果发现页面叠在一起或打不开，先确认没有同时按住 shift。
</warning>

## 重连排序

链路被亏电断路挂起后，从端会周期性申请重连。一根主端同时收到多个申请时，按排序逐个裁决。

排序是**每根杆一份**的，在配置页里调整：

- **首要因素**：优先级优先，还是需求优先（需求 = 从端的平均缺口）
- **时间因素固定升序、没有开关**：两个因素都相同时，先建立的链路先被考虑

服务端配置里的「重连排序」是**存档级默认**：进世界后的头一次结算会把它复制给**还没有设定**的杆。

- 已经有设定的杆会被跳过，玩家调过的顺序不会被默认值盖掉
- 这个补齐动作是幂等的，不会重复改

## 锁定

手持**铁砧锤**，**shift + 右键**一根杆，切换锁定。

**锁定的语义是「忽略红石造成的开关切换」**：锁定后给它红石，它的开关不会动，既不会被断电，也不会因为「断电再上电」触发开关重启后的重连。

- 锁定**不影响**优先级
- 提示框里只有锁定状态下才会出现「锁定」一行
- 解锁时会主动刷新一次方块状态，避免杆停在锁定期间的旧开关上

## 亏电断路

主端所在电网**账面连续亏电**超过 `manualLinkDeficitTicks`（默认 300 刻，约 15 秒）时，主端会按**平均净流出从大到小**依次挂起自己的连接，每挂一条重新评估是否仍然亏电。

- 被挂起的连接进入「已挂起」状态：**定义不删除**，只是停送电
- `manualLinkDeficitTicks = 0` 表示永不自动断开
- 断路只发生在主端一侧——从端没有电时不会主动断开连接

<info>
跨维度链路有损耗时，损耗计在**主端**头上：要送达 `N`，主端得付出 `N / (1 − 损耗)`。所以主端「看着有电」却持续亏电时，先检查损耗系数。
</info>

## 挂起后的重连

挂起的连接不会就此报废，从端会自己申请回来：

| 项 | 说明 |
| --- | --- |
| 申请周期 | 从端每 `reconnectRequestInterval` 刻（默认 200 刻，约 10 秒）申请一次 |
| 裁决依据 | 主端的**滚动平均富余**是否盖得住从端的平均缺口；窗口未预热时不裁决 |
| 批准后 | 主端从富余里扣掉这份额度，连接恢复「活跃」 |
| 被拒绝 | 从端继续等下一个周期；一次拒绝不会让后面的申请饿死 |
| 前置条件 | 两端杆都必须在线 |

## 开关重启

把杆的开关**关掉再打开**（OFF → ON）时会：

- 重置该杆的全部运行时值（亏电计时、平均窗口、重连冷却）
- 让被挂起的连接**直接恢复**

这是「手动拉好的线不该因为重启就没了」的实现方式。

## 看懂提示框

对着杆看，物品提示里会出现这些内容：

| 行 | 说明 |
| --- | --- |
| 总耗电量 / 总发电量 | 本体原有的电网统计 |
| 总交换电量 | 本附属插入，紧跟「总发电量」，只在有交换时出现 |
| 拉电线： | 本附属的连接信息块 |
| 上下游计数 | 形如 `2>>从端` 与 `主端>>3`，表示这根杆作为从端被几条连接指向、作为主端带了几条 |
| 外送电量 / 内收电量 | 本拍的送出与收到量，为 0 时隐藏 |
| 优先级 | 这根杆的优先级 |
| 锁定 | 仅锁定时出现 |

数值使用本体统一的电力单位显示；按住 **Shift** 可以展开更精确的读数。
