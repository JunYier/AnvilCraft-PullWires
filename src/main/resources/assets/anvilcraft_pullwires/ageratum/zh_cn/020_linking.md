# 绑定连接

自动组网可以「把杆并成一张电网」，绑定连接则可以「两张电网之间拉一条**单向**通道」，两者互不干扰，但仍然不建议在自动组网范围内手动建立连接，尽管后者会被电网结算规则绕过。

## 绑定与解绑

| 动作 | 结果 |
| --- | --- |
| **右键**一根已放好的杆 | 它成为**主端**，绑定记在你手持的输电杆或磁盘上 |
| **shift + 右键**（对着空气也行） | 解除绑定 |

绑定**不消耗**：放下一根杆建好连接后，绑定还在，可以继续放第二根、第三根。

<info>
点错杆了不用解绑重来——直接右键另一根杆，主端会被覆盖成新的那根（仅限输电杆，磁盘无效）。
</info>

## 三种建链方式

### 1. 放杆

手持一根杆右键主端 → 走到目标位置放下 → 建立连接。

### 2. 磁盘粘贴

磁盘已记着主端时，**右键另一根已放好的杆**，当场建链，被点的那根成为**从端**。

这一下不会清掉磁盘里的主端，所以可以对着很多根杆连续粘贴。

空磁盘右键杆 = 把主端记进磁盘。

<tip>
跨维度场景推荐用磁盘：你不好拿着杆穿过传送门之后再「放下」，但可以拿着磁盘过去，右键已经放好的那根跨维度杆。
</tip>

### 3. 副手磁盘 + 主手放杆

把已绑定的磁盘放在**副手**，主手拿杆照常放下，同样建立连接。由配置项 `allowDiskBinding` 控制（默认开）。

## 引导与距离条

绑定后，主端到你瞄准的放置位置之间会出现：

- **粒子引导带**：从主端杆顶连到放置预览的顶部；超出范围时不再生成
- **距离条**（屏幕上方）：前 3/4 是绿色，表示还在范围内；后 1/4 是红色，表示已超出范围。

主端是跨维度杆时，距离条改为满格绿色，并显示「无距离限制」。

## 超距自动解除

拿着绑定走太远，绑定会自动解除，免得你带着一条永远连不上的绑定到处跑。

| 项 | 说明 |
| --- | --- |
| 阈值 | 手动连接范围 × `cancelDistanceMultiplier`（默认 2 倍） |
| 表现 | 距离条消失、动作栏提示「离主端太远，已自动解除绑定」、播放音符盒音效 |
| 例外 | 主端是跨维度杆时**永不**因距离解除 |

## 失败提示

| 情况 | 动作栏提示 | 绑定 |
| --- | --- | --- |
| 超出手动连接范围 | 超出手动连接范围（当前距离 / 上限） | 保留 |
| 有一端不是跨维度杆却想跨维度 | 跨维度连接只能在两根跨维度输电杆之间建立 | 保留 |
| 这两根杆之间已有同向连接 | 这两根杆之间已经存在同向连接 | 保留 |
| 粘到自己身上 | 这根杆就是当前记下的主端，不能连到它自己 | 保留 |

失败时绑定一律保留，换个位置继续就行。

<warning>
`A → B` 与 `B → A` 是**两条独立的连接**，可以同时存在（互为主从），这在「互相借电」的场景里有用。但多跳转发不是靠这个实现的，见[结算与优先级](030_settlement.md)。
</warning>
