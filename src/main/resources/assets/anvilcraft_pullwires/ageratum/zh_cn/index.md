# 铁砧工艺：拉电线

> 本附属给《铁砧工艺》的输电杆加了一种新的连接方式：**绑定连接**。
> 它可以让任意两根杆之间拉出一条**单向**电力通道，距离远超自动组网范围，甚至跨越维度。

## 它解决什么问题

本体的输电杆靠「自动组网」连成电网，范围有限。当你想把电送到很远的地方、
或者送到另一个维度时，自动组网帮不上忙。绑定连接就是为这件事准备的：

- 一根杆负责**送电**（主端），另一根负责**收电**（从端）
- 电力**单向**流动，从端不会反向回流
- 可以一根主端带多根从端（一主多从）
- 两端都是**跨维度输电杆**时，还可以跨维度

## 三分钟上手

1. 手持一根输电杆（或一张磁盘），**右键**已经放好的那根杆 → 它成为**主端**，
   屏幕上出现一条距离 Boss 条。
2. 走到目标位置，**放下**一根新的杆 → 自动建立连接，动作栏显示「已建立连接」。
3. 绑定**不消耗**：手里有多少根杆，就能连着放多少根。
4. **shift + 右键**（对着空气也行）解除绑定。

::: tip
不想用杆来「当钥匙」的话，可以用**磁盘**：空磁盘右键杆 = 把主端记进磁盘；
再右键另一根杆 = **粘贴**，当场建链。这就是跨维度场景最常用的手法。
:::
