# 铁砧工艺：拉电线

本附属给《铁砧工艺》的输电杆加了一种新的连接方式：**绑定连接**。它让你在**任意两根杆**之间拉出一条**单向**电力通道，想怎么拉就怎么拉，两端都是跨维度杆时还能跨越维度拉电线。

## 它解决什么问题

本体的输电杆靠**自动组网**连成一张电网，两杆离得太远就并不到一起。想把电送到很远的地方、或者送到另一个维度时，自动组网帮不上忙。

绑定连接就是为这件事准备的：

- 一根杆负责**送电**（主端），另一根负责**收电**（从端）
- 电力**单向**流动，从端不会把电送回主端
- 一根主端可以同时带多根从端
- 主端带优先级的分配、亏电自动断开、断开后自动重连都具备
- 两端都是**跨维度输电杆**时，可以跨越维度

## 三分钟上手

1. 手持一根输电杆（或一张**磁盘**），**右键**已经放好的那根杆——它成为**主端**，屏幕上出现一条距离条。
2. 走到目标位置，**放下**一根新的杆，自动建立连接。
3. 手里的杆**不会**因为建立连接而消耗，可以连着放很多根。
4. **shift + 右键**（对着空气也行）解除绑定。

<tip>
不想用杆当「钥匙」时，用**磁盘**更省事：空磁盘右键杆 = 把主端记进磁盘；再右键另一根杆 = **当场粘贴建链**。跨维度场景建议都用磁盘。
</tip>

## 关键概念

| 概念 | 含义 |
| --- | --- |
| **主端 / 从端** | 一条连接的两个端点。只有主端能送电给从端 |
| **三档范围** | 供电 / 自动组网 / 手动连接，三者用途完全不同，见[三档范围](010_ranges.md) |
| **绑定** | 「哪根杆是主端」记在你手持的物品上，放下杆时用它建链 |
| **结算** | 每隔固定刻数跑一次，把主端的富余按优先级分配给从端 |
| **挂起** | 主端长期亏电时主动停掉自己的连接；之后从端会周期性申请重连 |
